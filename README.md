# Socdaal

Socdaal (working name) is a travel platform for Somalia. Its first product, **Boosteejo**, replaces the bus station manager's paper notebook: the manager manages the buses at a boosteejo and registers passengers.

| Folder | What it is | Stack |
| --- | --- | --- |
| [`api/`](api/) | Backend: boosteejos, routes, bus queue, passengers, live updates | NestJS, TypeORM, MySQL |
| [`web/`](web/) | Manager app (coming next) | Angular |
| [`docs/`](docs/) | Plans and notes | |

## Products

- **Boosteejo**: bus station records, queue and seat booking (Stages 1–2)
- **Dalmar**: tourism, hotels, guides and trips (Stage 3)
